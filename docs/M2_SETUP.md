状态：已编写最小战斗闭环源码，等待 Unity 编译与试玩。以 [M1 导入步骤](M1_SETUP.md) 创建工程、复制源码并重新生成场景。已有 M1 场景不会自动出现新木桩，菜单会生成一个新的场景目录。

## 当前玩法

第一位加入者是冰角色，第二位是火角色。两人就绪后可移动和攻击庭院中唯一的绿色训练木桩。攻击自动瞄准木桩，玩家只需进入射程、绕过障碍并按攻击键。

| 参数 | 冰角色 | 火角色 |
| --- | --- | --- |
| 攻击键 | Space / 手柄左侧主按钮 | Space / 手柄左侧主按钮 |
| 射程 | 8 个 Unity 世界单位 | 2.8 个 Unity 世界单位 |
| 基础伤害 | 10 | 25 |
| 冷却 | 0.45 秒 | 0.65 秒 |
| 元素效果 | 冻结 2.5 秒，新冰击刷新持续时间 | 冻结有效时附加 35 伤害并消费标记 |

木桩初始血量 140。一次冰击后血量为 130，紧接一次火击造成 60 点破冰伤害，血量变为 70；再完成一次同样组合即可击败木桩。致死伤害按剩余血量截断，界面显示实际扣除值。

冻结恰好到期时的火击按普通 25 点伤害结算。同一个攻击 ID 只能对木桩结算一次，同一个冻结状态只能被消费一次。两名玩家同帧按攻击时按 P1 冰、P2 火的顺序处理，因此可触发破冰。当前是直接射线命中加短暂光束，不是有飞行时间的冰弹或近战动画。

墙体和障碍会阻挡命中；队友不会挡住攻击，也不会受到友军伤害。被挡住、超出射程或木桩已经击败的攻击不消耗冷却。攻击按下时触发一次，长按不会自动连发。

木桩击败后变灰。使用已绑定设备的 R / 手柄 Select（View、Share 等名称依设备而异）恢复满血并清空冻结和命中记录；玩家位置、设备分配和仍未结束的技能冷却保留。存活中的木桩不会响应重置键。

## 暂停和反馈

- Esc / 手柄 Start 手动暂停；设备断开、玩家未到齐或窗口失焦时也停止玩法推进。
- 冻结和冷却使用会话的 `SimulationClock`，只累计可操作时长。暂停三十秒不会让冻结过期，也不会让技能提前冷却完成。
- 0.12 秒光束和镜头平滑属于视觉反馈，可以在暂停期间自然结束；它们不参与伤害和状态计时。
- HUD 显示设备状态、木桩血量 / 冻结 / 击败状态、最近伤害、每位玩家的射程 / 遮挡 / 冷却反馈。
- 木桩目前没有 AI；冻结通过状态和配色呈现，不代表已实现移动敌人被定身。

## 潜在问题与边界

- 首次 Unity 导入可能暴露引擎、包或编辑器 API 的兼容问题；当前没有可验证的具体补丁组合。
- 射线和 CharacterController 的真实碰撞行为、起点位置、墙角及手柄热插拔需要实机测试。
- 简易 HUD 使用 IMGUI，可能遮住庭院或在小窗口换行截断；共享镜头只跟踪玩家，远离木桩时不保证木桩持续可见。
- 光束使用占位材质，尚无动画、音效、命中特效和面向色觉差异的完整视觉设计。
- 目前只有一个不会反击的训练目标，没有角色血量、复活、敌人 AI、波次、房间或 Boss。
- 攻击范围和伤害是可调原型参数；静态测试不能判断游戏手感或合作乐趣。
